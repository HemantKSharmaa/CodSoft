Java Console Projects.
Welcome to my repository of Java-based console projects, created as part of my journey in learning and practicing Java programming. These mini-projects are simple yet functional applications built using core Java concepts like loops, conditionals, methods, OOP, and user input handling.

📌 Projects Included
- Number Guessing Game
A simple game where the user tries to guess a randomly generated number within limited attempts.

- Grade Calculator
Calculates the average marks and assigns grades based on user input for different subjects.

- ATM Interface
A basic simulation of an ATM machine with options like checking balance, depositing, and withdrawing money.

🛠️ Technologies Used
Language: Java (Core)
Environment: Console-based (Command Line Interface)
Tools: Any IDE like IntelliJ, Eclipse, or simple text editors with terminal

💡 Purpose
The main goal of this repository is to :
- Practice and reinforce Java basics
- Learn problem-solving using logic and programming
- Lay the foundation for object-oriented programming
